# CARE-Rx 同事评审指南

## 评审目标

本轮评审用于发现临床内容、工作流、可用性和局域网部署方面的问题，不代表系统已经通过机构临床试点或信息安全审批。

## 体验前

1. 仅使用虚构病例代号，不输入姓名、床号、病历号或自由文本病史。
2. 建议分别测试 M01、M07、M08，并覆盖安全阻断、信息不完整、最低/最高适用等级和无匹配场景。
3. 不要将页面输出用于真实患者治疗或交给护工执行。

## 建议场景

| 场景 | 输入重点 | 预期结果 |
|---|---|---|
| 安全阻断 | 任一红旗选择“是” | 不显示处方，提示暂停和人工复核 |
| 信息不足 | 任一安全项选择“不明确” | 不显示处方，要求补全信息 |
| M01 匹配 | M01 + F1～F3 | 显示 M01 正式处方，个案确认前不可导出 |
| M07 匹配 | M07 + F3～F5 | 显示 M07 正式处方 |
| M08 匹配 | M08 + F2～F4 | 显示 M08 正式处方 |
| 等级不匹配 | 模块与适用等级不一致 | 不显示其他模块或越级处方 |
| 个案确认 | 点击治疗师确认 | 保持当前访问主机，显示打印/另存 PDF |

## 反馈格式

提交 Issue 时请写明：

- 评审类型：临床内容、流程、界面、技术或安全。
- 使用的虚构病例代号和分类组合。
- 预期结果与实际结果。
- 风险级别：阻断、重要、一般或建议。
- 建议修改内容和理由。

截图必须检查并遮盖所有真实患者或机构敏感信息。不要上传 `.env.local`、密码、Cookie、日志全文或真实导出文件。

## 临床反馈特别要求

对处方提出修改时必须指出处方 ID 和版本，并说明要修改的适用等级、剂量、辅助、禁忌、终止、进阶或降级字段。临床规则或处方的每次修改都必须更新审核记录和测试，不能直接静默覆盖 `1.0.0`。
