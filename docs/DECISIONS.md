# 已确认决策与保守默认方案

更新日期：2026-08-17。

## 已确认

| 主题 | 决策 | 影响 |
|---|---|---|
| 访问范围 | 机构局域网内电脑、平板和手机访问 | 采用一台受控 Windows 主机运行服务，终端只通过网页访问；不得共享 SQLite 文件 |
| 临床责任 | 使用本项目的治疗师审核、确认处方 | 每次确认必须绑定已登录治疗师；系统不自动签发 |
| 目标模式 | P/M/R/C/H 允许多选 | 必须区分主目标与次目标，并检查目标冲突 |
| 身份认证 | 网页登录 | 需要治疗师账号、密码策略、会话超时、登录限速和管理员账户管理 |
| 患者数据 | 填写后查看匹配处方，不要求系统留存 | 患者输入和匹配结果仅存在于短期会话；退出、超时或导出后清除 |
| 导出 | 希望支持 | 导出前由治疗师确认；文件嵌入内容版本、规则版本、确认人和时间，由机构负责保存 |

## 由项目采用的保守默认方案

1. **红旗处置**：系统只显示机构预先配置并批准的联系人和处置路径。未配置时红旗阳性只允许显示“停止评估/训练并按机构流程联系医疗人员”，不得给出自拟临床处置。此配置是试点发布门槛。
2. **评估工具**：阶段 1 先使用原创、结构化功能观察条目，不复制未获许可量表。任何正式量表仅在确认中文版本、版权许可、评分规则和使用场景后加入。
3. **F0–F5 判定**：保存各能力域证据，不以总分替代临床判断；跨等级矛盾时给出暂定等级并要求治疗师确认。精确阈值全部标记“待临床审核”。
4. **康复潜力**：使用医学稳定性、主动参与、学习/认知、近期功能轨迹、照护资源五个结构化维度，不计算未经验证的单一总分。
5. **首版边界**：M07 仅面向经安全筛查后适合功能训练的慢性腰痛；M08 仅面向既往已明确脑卒中且医学稳定者；M01 中压疮、营养、吞咽等只做协同提醒或转介，不由本系统诊断或治疗。全部具体标准待临床审核。
6. **试点门槛**：所有安全阻断和权限测试必须 100% 通过；临床匹配采用治疗师逐例一致性审核，不先虚构准确率指标。首轮建议由 2–3 名治疗师完成至少 30 个虚构病例评审，高风险缺陷为零后才可进入受控试用。

## 无留存模式带来的范围变化

当前首版不能在系统内可靠支持每日执行记录、2–4 周纵向复评、患者历史处方查询或患者级审计。上述能力进入“持久化临床记录扩展”，只有在机构批准数据留存期限、删除、备份、访问控制和合规方案后实施。
