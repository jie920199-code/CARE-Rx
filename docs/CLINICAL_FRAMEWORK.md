# 临床框架

> 本文是结构草案。具体量表、阈值、训练剂量、禁忌证及转诊路径均为“待临床审核”。

## 1. 决策输入

1. 安全状态：紧急红旗、非紧急转诊、禁忌证、生命体征边界、疼痛/神经变化。
2. 功能等级：F0–F5，并记录判定依据、评估者和置信/人工复核状态。
3. 核心问题：M01–M10；首版只激活 M01、M07、M08，其余可记录但不匹配处方。
4. 康复潜力：建议拆成参与能力、学习/认知、医学稳定性、既往轨迹、支持条件，而不是单一主观分数。
5. 照护条件：可用人员、辅助人数、技能、器械、空间、时间、监护能力。
6. 目标模式：P、M、R、C、H；允许多选，但必须指定一个主模式、零到多个次模式及理由。

## 2. 安全优先决策流

```text
资料完整性检查
  -> 紧急红旗？是：停止流程并按机构路径处置
  -> 非紧急转诊/需医生确认？是：暂停相关模块，允许记录处置
  -> 训练特异禁忌或 AX？是：排除或替代该训练
  -> 完成功能分级、问题与目标模式
  -> 规则匹配候选处方
  -> 治疗师审核/修改/拒绝
  -> 确认后生成角色化视图并可导出
```

安全门不得只依赖总分；红旗应保存逐项答案、来源、时间、处置和关闭人。

## 3. F0–F5 初步判定原则

| 等级 | 核心锚点 | 需要补充定义 |
|---|---|---|
| F0 | 医学不稳定、终末期或无法主动参与，以舒适照护为主 | “无法参与”和医学不稳定的操作性定义 |
| F1 | 完全卧床，翻身与坐起完全依赖 | 与 A4/A5 的关系、短暂参与如何归类 |
| F2 | 可参与床上活动或短时坐起 | “短时”、坐位支持与耐受阈值 |
| F3 | 能坐位，站立/转移需辅助 | 坐位独立性、站立和转移最低条件 |
| F4 | 可在辅助或监护下行走 | 距离、设备、A1–A3 边界 |
| F5 | 独立步行或完成主要活动 | 室内/室外、认知监督和器械独立性 |

建议允许 `provisional`（暂定）等级，矛盾信息触发治疗师人工判定，不用算法强行归类。

## 4. 首版模块边界

- **M01 长期卧床与废用综合征**：体位管理、床上活动、坐起耐受、关节活动、力量与转移准备；压疮、营养和护理问题只做协同提醒，不替代相应专业评估。
- **M07 慢性腰痛**：仅处理经安全筛查后、适合保守功能训练的慢性腰痛；新发严重神经症状、创伤、感染/肿瘤等疑点进入红旗路径。具体筛查表待临床审核。
- **M08 脑卒中运动功能障碍**：处理已明确病史后的运动功能训练，不诊断卒中；疑似急性卒中必须进入紧急路径。吞咽、言语和认知可记录或转介，不在首版运动处方核心范围。

## 5. 多问题与目标冲突

- 一位老人可有多个模块和多个目标，但必须选定主问题、次问题及理由。
- 处方组合前先做训练级禁忌、重复剂量、总负荷、体位和人员/器械冲突检查。
- 如规则给出互斥建议、资源不足或信息缺失，状态为 `needs_review`，不得生成可导出的已确认方案。
- F 等级不是唯一剂量依据；症状反应、安全状态和照护条件可使辅助等级降低或设为 AX。

## 6. 复评（持久化扩展）

原产品目标中的复评窗口为确认后 2–4 周，但首版不保存基线，不能在系统内完成纵向复评。启用持久化扩展后，复评必须引用基线、相同或可比指标、依从性、异常事件和照护条件变化，并由治疗师选择维持、进阶、降级、暂停或转诊。相关阈值待临床审核。
