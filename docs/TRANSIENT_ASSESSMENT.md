# 临时评估入口

状态：安全原型；不得用于真实临床决策。

## 已开放范围

- 仅登录治疗师可进入。
- 只接受虚构病例代号、年龄段、M01/M07/M08 多选和三项安全筛查草案。
- 数据仅保存在单个 Node.js 进程的内存中，空闲或绝对超时、主动清除及服务器重启都会使其失效。
- 不提供姓名、身份证、联系方式、病历号或自由文本字段。

## 安全结果

- 任一安全项为“是”：`safety_blocked`，停止后续匹配。
- 任一安全项为“不明确”或缺失：`needs_information`，停止后续匹配。
- 全部为“否”：`manual_review_required`。由于筛查、规则和处方仍待临床批准，依然不允许处方匹配。

所有结果的 `prescriptionMatchingAllowed` 均为 `false`。当前页面不会诊断、生成处方、确认处方或导出护工执行版。

## 后续临床审核

开放任何处方匹配前，必须完成安全筛查措辞、触发级别、机构处置路径、F0～F5操作定义和M01/M07/M08处方内容审批，并为每项变化补充测试。
