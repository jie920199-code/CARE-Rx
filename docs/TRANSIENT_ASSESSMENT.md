# 临时评估入口

状态：公开评审原型；不得输入真实患者信息，尚未获准用于机构临床试点。

## 已开放范围

- 仅登录治疗师可进入。
- 只接受虚构病例代号、年龄段、M01/M07/M08 多选、F0～F5、A0～AX、P/M/R/C/H 和三项安全筛查。
- 数据仅保存在单个 Node.js 进程的内存中，空闲或绝对超时、主动清除及服务器重启都会使其失效。
- 不提供姓名、身份证、联系方式、病历号或自由文本字段。

## 安全结果

- 任一安全项为“是”：`safety_blocked`，停止后续匹配。
- 任一安全项为“不明确”或缺失：`needs_information`，停止后续匹配。
- 全部为“否”：`manual_review_required`，可按模块与功能等级读取已批准处方，但仍须登录治疗师完成本次个案确认。

安全阻断和信息不足时不匹配处方。个案确认前不得执行或导出；确认后只开放当前页面的打印/另存 PDF，不保存患者档案。

## 后续临床审核

M01、M07、M08 三份处方已形成 `approved@1.0.0` 和独立审核记录。安全筛查措辞、机构处置路径、F0～F5 操作定义和更多处方内容仍需持续评审；任何临床修改都必须建立新版本、审核记录和相应测试。
