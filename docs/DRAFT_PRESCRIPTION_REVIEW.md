# 首版处方草案临床审核说明

状态：`draft + pending_clinical_review`。以下处方只能作为治疗师审核材料，不能签发、导出或交由护工执行。

## 草案范围

| 草案 | 模块 | 初始适用等级 | 主要方向 |
|---|---|---|---|
| RX-M01-BED-MULTICOMPONENT | M01 | F1～F3 | 床上主动参与、低负荷抗阻与功能任务 |
| RX-M07-GRADED-ACTIVITY | M07 | F3～F5 | 保持活动、分级运动与目标相关功能练习 |
| RX-M08-TASK-PRACTICE | M08 | F2～F4 | 任务特异性重复练习、转移与移动能力 |

F0、AX、安全阻断或信息不足状态不会显示候选处方。其他等级与模块不匹配时同样不会显示。

## 证据基础

- M01：WHO建议功能下降老年人进行包含力量、平衡、柔韧和有氧成分的多组分活动；2024年一项80岁以上卧床人群随机试验使用低负荷抗阻训练并报告力量和部分心肺指标改善。[WHO身体活动指南](https://www.who.int/publications/i/item/9789240015128)，[PMID 38875406](https://pubmed.ncbi.nlm.nih.gov/38875406/)
- M07：NICE NG59建议提供自我管理信息、鼓励保持正常活动，并考虑根据能力和偏好选择运动方案；牵引、常规超声和PENS等不应作为推荐治疗。[NICE NG59](https://www.nice.org.uk/guidance/ng59/chapter/Recommendations)
- M08：2023版英国国家卒中临床指南将任务特异性、重复和强化练习作为运动恢复的主要方法，并要求在医学稳定、目标和个体能力基础上选择剂量。[运动恢复章节](https://www.strokeguideline.org/chapter/motor-recovery-and-physical-effects-of-stroke/)，[康复原则章节](https://www.strokeguideline.org/chapter/rehabilitation-and-recovery-principles-of-rehabilitation/)

草案中的具体次数、时长、主观强度范围和等级适用范围，是对上述证据进行的初步本地化设计，不等同于指南逐字推荐，必须由本项目治疗师逐条审核。

## 必须逐条确认

1. 训练名称、步骤和适用功能等级。
2. 每项次数、组数、时长、频率和强度范围。
3. A0～A5实际允许范围，以及哪些项目必须仅由治疗师执行。
4. 禁忌证、注意事项和机构紧急处置路径。
5. 终止、进阶、降级和替代训练标准。
6. 复评指标是否适用于养老机构现有设备与人员。
7. 是否需要按功能等级进一步拆分成多个不可变处方版本。

只有完成审核记录、指定审核人和审核时间，并将内容状态显式提升为 `approved` 后，后续阶段才可设计签发和护工执行版。
