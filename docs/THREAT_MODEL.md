# 局域网首版威胁模型

## 保护对象

- 治疗师账号和会话。
- 当前内存中的临时评估输入与匹配结果。
- 已批准的规则、处方和机构安全配置。
- 治疗师导出的处方文件。
- 非患者审计记录和系统配置。

## 信任边界

```text
机构终端浏览器
  -> 局域网与 HTTPS
    -> Windows 应用主机
      -> Next.js 服务进程
        -> 临时内存会话
        -> SQLite（仅账号、配置、内容版本、非患者审计）
```

终端、局域网和应用主机均不是天然可信。系统不得因为“只在内网”而关闭认证、HTTPS、会话保护或权限检查。

## 主要威胁与控制

| 威胁 | 主要控制 | 验收证据 |
|---|---|---|
| 未授权终端访问 | 网页登录、最小权限、登录限速、机构终端准入 | 未登录和停用账号访问失败 |
| 会话窃取 | HTTPS、Secure/HttpOnly/SameSite Cookie、会话轮换、超时 | Cookie 与超时测试通过 |
| 跨站请求 | SameSite 与服务端 CSRF 防护 | 跨站状态变更失败 |
| 患者输入落盘 | 内存会话、禁止请求体日志、错误脱敏、退出/超时清除 | 数据库、日志和备份扫描无输入内容 |
| 未批准内容导出 | 临床状态校验、治疗师再次确认、版本锁定 | 未确认或未批准导出测试失败关闭 |
| 内容被篡改 | 发布包哈希、只读批准版本、版本引用 | 篡改后校验失败 |
| 局域网横向移动 | 主机防火墙只开放必要端口、禁止公网和文件共享数据库 | 端口与监听地址检查 |
| 导出文件泄露 | 默认无直接身份字段、明确机构保管责任、受控保存与打印 | 导出检查清单和机构制度 |
| 服务异常导致绕过 | 默认失败关闭、规则异常停止匹配 | 故障注入测试返回安全错误 |

## 明确不保护的边界

首版无法控制用户导出后自行复制、发送或拍照，因此必须依赖机构的文件保存、打印、传输和销毁制度。系统不得宣称“无留存”等于“没有隐私风险”。
