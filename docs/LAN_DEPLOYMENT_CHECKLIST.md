# 局域网部署检查清单

## 主机

- 使用机构管理的 Windows 主机和独立低权限服务账户。
- 启用磁盘加密、自动屏幕锁、系统更新和恶意软件防护。
- SQLite 文件不放在网络共享目录，只有应用服务账户可访问。
- 仅备份账号、配置和批准内容；确认备份中不存在患者会话数据。

## 网络

- 使用固定内网地址或机构 DNS 名称。
- 只监听批准的内网接口，不绑定公网接口。
- 通过主机防火墙仅开放应用所需端口和批准的内网网段。
- 使用机构认可的 HTTPS 证书，并在各终端验证证书信任。
- 路由器不得配置公网端口转发；不得使用临时公网隧道。

## 账号与会话

- 每位治疗师使用独立账号，禁止共用账号。
- 管理员与治疗师权限分离；管理员不默认拥有临床签发权。
- 账号停用、密码重置和权限变更有责任人及非患者审计记录。
- 验证退出、空闲超时、绝对超时和服务器重启都会清除患者会话。

## 导出

- 未经治疗师确认或包含未批准内容时禁止导出。
- 导出文件包含治疗师、时间、规则版本、处方库版本、安全配置版本和免责声明。
- 默认不收集或输出姓名、证件号、电话、地址和病历号。
- 机构明确导出后的保存、打印、传输和销毁制度。

## 上线阻断项

任一以下条件不满足时不得试点：红旗路径未批准、HTTPS 未启用、共享账号、患者输入进入数据库/日志/备份、未批准内容可导出、SQLite 通过文件共享提供给终端。
