# 决策状态与发布前确认项

原 9 个规划问题已根据项目负责人答复和保守默认原则完成处理，决策详见 `DECISIONS.md`。

## 已关闭

1. 访问范围：机构局域网多终端。
2. 处方确认：使用系统的治疗师负责审核确认。
3. 目标模式：允许多选，区分主目标和次目标。
4. 登录：网页登录。
5. 患者数据：首版仅在短期会话中使用，不做系统内长期留存。
6. 导出：支持治疗师确认后的版本化导出。

## 已采用默认方案

- 红旗路径由机构配置；未配置时不得进入试点。
- 首版先使用原创结构化评估条目，第三方量表须完成授权审核。
- F0–F5 跨域不一致时由治疗师确认，具体阈值待临床审核。
- 康复潜力采用五维结构，不使用未经验证的总分。
- M01/M07/M08 使用 `DECISIONS.md` 中的保守边界。
- 首轮建议 2–3 名治疗师评审至少 30 个虚构病例；安全阻断和权限测试要求 100% 通过。

## 发布前仍须由机构填写，但不阻塞技术规划

1. 红旗联系人、升级顺序、响应时间和夜间/离线流程。
2. 治疗师账号开通、停用、密码重置和管理员责任人。
3. 局域网主机、防火墙、HTTPS 证书和终端准入责任人。
4. 导出文件的保存位置、访问权限、传输、打印和销毁制度。
5. 所有临床阈值、禁忌证、剂量和处方内容的治疗师审核记录。
